# Сумма Фортуны — Позитрон v1.0

Готовое PWA-приложение для GitHub Pages.

## Рекомендуемый репозиторий
`arsazet17/pozitron-summa-fortuny`

Тестовый `arsazet17/pozitron-fortune-test` лучше оставить для API/диагностики, чтобы лабораторные workflow не смешивались с приложением.

## Встроено
- архив 9200 фактических тиражей;
- В→В / В→Г / Г→В / Г→Г;
- сокращение только слева 6→5→4→3→2;
- В1 / В2 / В3 без скрытых тай-брейков;
- Combo→Σ по 6 позициям;
- NEXT / SKIP1 / SAME1 / SAME2 / DIAG_R / DIAG_L;
- статистика только по реально зафиксированным прогнозам;
- Сумма / Комбинация / Позиции;
- выплаты по присланным правилам;
- суперприз по номеру билета отключён.
