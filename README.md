# Сумма Фортуны — Позитрон v2.0.1

PWA для GitHub Pages. Расчёт выполняется в GitHub Actions (`Fortune Auto Update`), браузер только показывает уже зафиксированный `data/current-forecast.json`.

## Что показывает приложение

Открываешь — и сразу видно, что ставить на следующий тираж:

| Ставка | Что ставить | Шанс | Зачем |
|---|---|---|---|
| Сумма · Чаще попадать | 20, 21, 22 | 27,4% | самые частые суммы |
| Сумма · Выгоднее | 19, 21, 23 | 26,0% | 19 и 23 платят 2 800 ₽ вместо 2 450 ₽ |
| Комбинация | 3 числа × 2 раза | 3,9% | выплата 17 500 ₽, в 3 раза выгоднее любой другой категории |
| Позиции | — | — | у любой комбинации шанс одинаковый |

Рядом — «Как сыграли эти ставки» за сутки / неделю / месяц / весь архив: сколько раз попали и сколько выплат пришло бы.

## Почему так

Архив показывает: шары выпадают как честные кубики — частоты шаров равные, частоты сумм совпадают с теорией.
Поэтому прогноз строится по точным вероятностям сумм (свёртка 6 кубиков, 46 656 исходов) и таблице выплат.
Семейства FAMILY, RAW, JUMP-TRACK и HARD RANGE убраны: они не давали попаданий сверх случайности, а HARD RANGE снижал шанс (24,8% против 27,4%).

## Цикл

1. Скачать страницу Лото-архива и добавить новые тиражи.
2. Проверить ранее зафиксированный прогноз (H — попал, M — мимо, U — прогноза не было).
3. Зафиксировать прогноз на следующий тираж. Уже зафиксированный прогноз не переписывается.

## Файлы данных

- `data/fortune-archive.csv` — архив тиражей.
- `data/current-forecast.json` — прогноз на ближайший тираж.
- `data/forecast-history.json` — все прогнозы с результатом (компактно, без подробностей).
- `data/forecast-ledger.json` — короткий журнал последних проверок.
- `data/rules.json` — таблицы выплат.
