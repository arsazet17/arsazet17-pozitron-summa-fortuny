# Сумма Фортуны — Позитрон v2.3.0

PWA для GitHub Pages. Расчёт выполняется в GitHub Actions (`Fortune Auto Update`), браузер только показывает уже зафиксированный `data/current-forecast.json`.

## Что показывает приложение

Открываешь — и сразу видно, что ставить на следующий тираж. Правила и выплаты взяты из раздела лотереи «Как играть → Условия победы»: ставка 550 ₽, выигрыш = 550 ₽ × коэффициент.

| Ставка | Что ставить | Шанс | Возврат в среднем |
|---|---|---|---|
| Сумма · Чаще попадать | 20, 21, 22 (×7, 3 850 ₽) | 27,4% | ≈ 64% |
| Сумма · Выгоднее | 19, 21, 23 (×8 / ×7) | 26,0% | ≈ 66% |
| Комбинация | Четыре одинаковых (×12, 6 600 ₽) | 5,2% | ≈ 63% |
| Позиции | — | — | у любой комбинации шанс одинаковый |

Рядом — «Как сыграли эти ставки» за сутки / неделю / месяц / весь архив: попадания, выплаты, сколько потрачено и итог.

Важно: «3 числа × 2» по правилам лотереи — это два числа по три раза (5 1 1 5 5 1, ×50), а «2 числа × 3» — три числа по два раза (4 4 6 2 6 2, ×14).
Крупные выплаты (суммы 6–8 и 34–36, «все одинаковые», 6 позиций) делятся между всеми победителями.

## Почему так

Архив показывает: шары выпадают как честные кубики — частоты шаров равные, частоты сумм совпадают с теорией, связей между тиражами и местами нет (χ², тест серий, автокорреляция, цепочки Маркова).
Поэтому прогноз строится по точным вероятностям (свёртка 6 кубиков, 46 656 исходов) и таблице выплат.

## Цикл

1. Скачать страницу Лото-архива и добавить новые тиражи.
2. Проверить ранее зафиксированный прогноз (H — попал, M — мимо, U — прогноза не было).
3. Зафиксировать прогноз на следующий тираж. Уже зафиксированный прогноз не переписывается.

## Файлы данных

- `data/fortune-archive.csv` — архив тиражей.
- `data/current-forecast.json` — прогноз на ближайший тираж.
- `data/forecast-history.json` — все прогнозы с результатом (компактно, без подробностей).
- `data/forecast-ledger.json` — короткий журнал последних проверок.
- `data/rules.json` — таблицы выплат.
